# Master Feature Mapping Matrix

## 1. Overview

This document represents the master functional and technical mapping of the GroCo Grocery Store enterprise platform. It connects every user-facing capability to its underlying frontend templates, backend PHP controllers, AJAX/API endpoints, database tables, and access control rules.

# GroCo Supermarket POS — Cashier & Store Operations Manual (2026)

## 1. Quick Keyboard Shortcuts Reference

| Shortcut | Function | Description |
| :--- | :--- | :--- |
| <kbd>F1</kbd> / <kbd>F2</kbd> | Focus Scanner | Immediately returns focus to the barcode scanner search input |
| <kbd>F3</kbd> | Search Customer | Focus customer phone lookup to link loyalty rewards |
| <kbd>F4</kbd> | New Customer | Opens quick customer enrollment modal |
| <kbd>F5</kbd> | Hold / Park Cart | Suspends current cart with reference note |
| <kbd>F6</kbd> | Suspended List | Opens suspended orders list to resume parked carts |
| <kbd>F7</kbd> | Discount Field | Focuses the discount override input |
| <kbd>F8</kbd> | Cash In / Out | Opens the Petty Cash drawer movement dialog |
| <kbd>F9</kbd> | Split Pay Modal | Opens multi-tender split payment modal |
| <kbd>F10</kbd> | Confirm Sale | Confirms transaction and triggers thermal receipt print |
| <kbd>ESC</kbd> | Clear Cart | Empties active checkout cart after confirmation prompt |

## 2. Produce & Weighted Items Handling

For vegetables, fruits, grains, and meats sold by weight:
1. Scan or click the produce item.
2. Click the quick weight buttons: `+0.25 kg`, `+0.5 kg`, `+1.0 kg`, or type the exact scale weight into the quantity input (e.g. `2.75`).
3. The line total updates in real time according to the price per kilogram/liter.

## 3. Handling Offline Situations

1. When the network connection is lost, the header badge changes to `● Offline Mode`.
2. Cashiers can continue scanning, adding produce, and completing sales normally.
3. Transactions are automatically queued in local memory.
4. When Internet connectivity returns, transactions synchronize automatically with zero cashier intervention required.
